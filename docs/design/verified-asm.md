# レジスタ命令列のモデルと証明

`std/asm.taut` は AArch64 風のレジスタ命令列を扱うライブラリである。
カーネルの規則、公理、外部アセンブラー、ネイティブコード生成は追加しない。

## 構文と意味論

`syntax!` が文法から `asm_syntax` の型付き AST を作る。`asm!` はその AST を
帰納型の `List(Asm::Instr)` の項へ展開する。マクロは証明を生成せず、展開された
プログラムと利用者の証明項は通常の検査を通る。

レジスタは `x0`、`x1`、`x2`。命令は `mov dst, src`、`add dst, lhs, rhs`、
`sub dst, lhs, rhs`。命令をセミコロンで区切り、末尾には付けない。
リテラルには一つ以上の命令を書く。意味論では空の命令列を `Nil` で表す。
大文字の命令名、別名レジスタ、即値、コメント専用記法は DSL の API に含めない。

`Asm::State` は三つの `U64` を持つ。`Asm::step` は入力状態からオペランドを読み、
宛先だけを書き換える。加減算は `U64::wrapping_add` / `wrapping_sub` による
2^64 を法とする演算であり、自然数の非負減算ではない。宛先とソースが重なる場合も
すべての読み取りは書き換え前の状態を参照する。`Asm::run` は先頭から順に実行する。

`Asm::Hoare` は入力条件から実行後の条件を導く命題であり、型を定義するだけでは
証明にならない。利用者がその型の項を渡す。具体的なプログラムと証明項は
[`examples/verified-asm.taut`](../../examples/verified-asm.taut)、受理・拒否の検査は
[`cases/verified-asm.eure`](../../cases/verified-asm.eure) に置く。

## 保証の境界

証明の対象はライブラリ内の抽象機械である。同じ命令名を使っても、CPU の公式意味論との
対応、命令エンコーディング、アセンブラー出力、生成物の実機実行を保証しない。

メモリー、ロード・ストア、NZCV フラグ、スタック、ABI、呼び出し規約、例外、分岐、
ループ、SIMD、部分レジスタ、実機への命令出力は扱わない。それらを要求する入力は
文法で拒否し、未対応部分の意味を省略して成功扱いしない。`mov` はモデルのコピー操作で
あり、実 ISA の別名命令のエンコーディングを選ぶ操作ではない。

解析表は `tauto syntax gen std` で生成し、`tauto syntax show std asm_syntax` で
生成型を確認する。通常の検査・lint と上記ケースでプログラムと証明項を検査する。
証明項の記述と、処理系がその項を実際に受理したという観測は区別する。
