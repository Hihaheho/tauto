# extensionality

純粋な依存関数の関数外延性を、明示的な公理 `funext` として提供するライブラリ。
利用するファイルが `src/Funext.taut` を import する。標準の prelude、`std/`、
`meta/` からは import されない。

`funext` は、各入力で値が等しい二つの関数が等しいと仮定する。
`funext_nondependent` は、入力に依存しない戻り値の型についての定理で、
`funext` に依存する。利用例は `examples/dependent.taut` にある。

公理と、その公理を直接・間接に使う証明の検査結果には `funext` が表示される。
ファイルを import しただけでは、独立した定理の公理依存は増えない。
このライブラリを利用しない証明は、公理なしの基盤を維持する。

## 範囲

引数の型と各戻り値の型は `Type` に属する。戻り値の型は入力に依存してよい。
より大きな宇宙の等式や、効果を持つ関数の観測同値は扱わない。

これは外延性の証明ではなく、利用者が選択する論理的な前提である。
カーネルの変換判定や簡約規則を変えず、新しい計算規則も持たない。
公理を含む体系の無矛盾性や標準形性が、このライブラリによって証明されるわけではない。
