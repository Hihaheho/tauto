# extract

抽出（証明言語のプログラムを Nib として書き出す段）の Tauto 実装。ホストの
`crates/tauto/src/extract.rs` と同じ出力を、`tools/selfhost-harness/tests/extract.rs`
で差分テストする（両方を `tauto fmt` で整形してから比べる）。

各ファイルを構文解析し、`elaborator` tote で全体を検査してから抽出する。検査を通らない
プログラムは抽出せずエラーにする。扱う範囲は次のとおり。

* `Type` の族は `shared enum` に、構成子が一つでフィールドがあれば `shared struct` に
  なる。パラメータ（型）は型パラメータに残り、証明のフィールドは落とす。
* `Prop` の族、`theorem`、`def` は書き出さない。
* `fn` は値のパラメータを残し、型のパラメータを `<A: Shared>` に、証明のパラメータを
  落とす。`fn f<T, U>` の型パラメータは境界のないものだけを `<T, U>` のまま残す。呼び出しからも対応する引数を落とす。構成子の呼び出しは `F::C(…)`、struct は
  `F { f: v }` と書く。
* `match` は結果型を落とし、パターンを `F::C(…)`・`F { f: x }` と書いて証明のフィールドの
  束縛を落とす。証明への `match` はその一つの腕になる。`let`、一引数のラムダ、関数値も扱う。
* 標準ライブラリの `List`・`Option`・`Ordering` は prelude から読み、`F::C(…)` と書く
  （ネストしたパターンも同じ）。`Bool` への `match`、`Zero`・`Succ(n)`（`n + 1`）、`if … else`、
  テキストリテラルも扱う。
* `module M { … }` はそのまま `module M { … }` と書き、中の関数は `M::f` の名前で呼ばれる。
* 名前はホストの出力境界と同じく割り当てる。ライブラリが宣言する名前（`tables/library-names.txt`）、
  ヘルパー、先に割り当てた名前と重なれば `_1`、`_2`…を付け、名前に使えない文字は `_` にする。
  束縛変数は宣言ごとに割り当てる。
* ヘルパー（`tables/helpers.txt`）はホストが書くとおりに前に置き、何も残らなければ何も書かない。

`tables/` の二つはホストから作る。`the_extraction_tables_are_the_hosts` が最新であることを
確かめ、`tauto gen-extract-tables` で書き直す（`--check` は比較だけ）。

`import "file"` は取り込みの閉包を依存順に書き出す。取り込み先の関数は、名前を付けたファイルから
届くものだけを書く（ホストと同じ）。`import std::…` の標準ライブラリの関数も、写像されないもの
（`List::append` など）は届くものだけを `append_1` のように書き出し、続けて同じ名前の `module`
は一つにまとめる。`Nat` への `match` は `let extract_nat := n` と `if … >= 1 … else` の連なりに、
`==`・`&&`・`||`・`<`・`<=`・`+` は必要最小限の括弧の中置に、`-` は `extract_nat_sub` に
なる。関数を値として渡せばラムダに開き、型を書いたラムダのパラメータは型を残す。`Text` の族を
読んだときはテキストのヘルパー（`tables/text-helpers.txt`）も前に置く。

拒否するもの（黙ってホストに任せない）: `elaborator` tote が検査しない入力全体（マクロ、
エフェクト、クラス）、`Type` の添字付きの族の一部（ホストの `dependent.rs`）、ガード、型の注釈のない
`let`、複数引数のラムダ、証明や型を結果とする関数、
証明だけを持つ一つの構成子の族は拒否する。`pub`・`pub(open)` は関数と型の両方を書き出す。
経路付きの名前の関数（`fn Bytes::concat`）は `module Bytes { … }` の中に書く。
`Text::of_nat($0)` のように自分の名前を呼ぶテンプレートを持つ関数は、ホストと同じく宣言をその呼び出しとして書き出す。
