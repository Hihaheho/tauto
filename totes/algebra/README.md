# algebra

型クラスの探索を使わず、演算と法則を明示的に渡す代数の基盤。
`src/Monoid.taut`、`src/Hom.taut`、`src/Group.taut` を必要に応じて import する。

- `AlgebraEq(u, A, a, b)` は数値宇宙に特殊化できる帰納的な等式。
  置換・対称律・推移律・合同を持ち、宇宙 0 では標準の `Eq` と相互変換できる。
- `AlgebraMonoid(u, A)` は単位元、二項演算、結合律、左右単位律をまとめる。
  `algebra_unit` と `algebra_op` は透明な射影。単位元の一意性も証明される。
- `AlgebraHom` は始域・終域のモノイドを添字に持ち、写像と単位元・演算の保存証明をまとめる。
  `algebra_compose(f, g)` の写像は `g(f(x))`。恒等射の左右の法則と結合律は各入力での等式。
  `identity_left/right` は合成に渡す第一・第二引数が恒等射であることを表す。
- 群はモノイド値、逆元関数、`AlgebraGroup` の法則証明という明示的な組で扱う。
  左右の逆元法則、左消去律、逆元の一意性を提供する。

同じ型に異なる構造を置ける。`examples/natural.taut` は自然数上の加法と乗法、
`examples/group.taut` は二元群、`examples/universes.taut` は宇宙 1・2 の構造、
宇宙をまたぐ準同型と宇宙 2 の群の法則を検査する。

## 整数と有理数の明示的な同値関係

`src/Integer.taut` は論理上の `Nat` の対 `(positive, negative)` から整数を構成する。
`IntegerEq` は交差した和の等式。共通の自然数を両成分に加えた代表や
`(n, n)` のゼロ代表を同一視するが、代表そのものの `Eq` は変えない。
加法・符号反転・減法・乗法は同値関係を保ち、加法の群法則、乗法の結合・可換・単位・
ゼロ法則、分配法則を持つ。`integer_of_nat` は単射で加法・乗法を保つ。

`src/Rational.taut` は整数の分子と、非零証明を伴う自然数の分母を持つ。
`RationalEq` は整数の同値関係による交差積の等式。既約分数や標準形を要求しない。
推移律では分母が非零であることから消去律を使う。
整数からの写像は同値関係の意味で単射で、加法・乗法を保つ。
`rational_inverse` と `rational_div` は対象の分子がゼロと同値でない証明を必須とする。
符号と正の大きさは自然数の再帰で求め、ゼロの場合はその非零証明と矛盾する。
逆数法則・逆数の一意性・除算の消去法則と、四則演算の代表独立性が証明される。
非零性も同値な代表へ移せる。非零証明の選び方に関係なく逆数は同値となる。

`src/Setoid.taut` の `AlgebraSetoid` は型と関係に対する反射・対称・推移律の証拠。
これらは宇宙 0 の明示的な setoid であり、ネイティブ商型ではない。
`AlgebraMonoid` や `AlgebraHom` が使う `AlgebraEq` と異なる関係なので、
生の代表をそれらの構造へ暗黙に登録しない。集合論的商、順序、最大公約数による正規化、
一般の setoid 環・体の階層はこの API の範囲外。

数学の宣言は公理なし。`nat_norm!` は自然数の多項式等式の証明項を作り、
生成した証明項は通常の検査を受ける。マクロの実装関数そのものを証明として数えない。
論理上の `Nat` は非有界だが、標準の抽出では `u64` に写る。
この構成は数学の証明ライブラリであり、任意精度の実行時整数・有理数実装の保証ではない。
`examples/rational.taut` は非標準の正負の分数、逆数、ゼロ代表、埋め込みを検査する。

`cargo test --locked -p tauto --test rational` は整数・有理数の全数学宣言の公理依存、
不正な分母・非零証明・偽の等式・生の代表の誤った同一視の拒否を検査する。

## 宇宙と論理的前提

宇宙引数はコンパイラの数値特殊化を使う。記号的な宇宙一般化はしない。
外延性を除くモジュールと例は公理なしで検査される。型クラス、カーネル、
標準ライブラリの等式や変換規則を変更しない。

`src/Extensionality.taut` だけは既存の `funext` を明示的に import し、
宇宙 0 の準同型の写像について、各点の等式から関数の等式を導く。
この定理の検査結果には `funext` が記録される。高い宇宙の関数外延性、
準同型の束全体の等式、証明の同一視を仮定しない。

AlgebraEq を使うモノイド・群の層は、商型・setoid・古典公理・一般の環や体の階層・補題の自動探索を提供しない。

## 検査

`cargo test --locked -p tauto --test algebra` は実例の全宣言、公理依存、
誤った法則・準同型・宇宙の拒否を検査する。

## 有限和・行列・線形写像

`src/Semiring.taut` は同じ carrier `R: Type` 上の加法・乗法モノイド値を
`AlgebraSemiring` の添字に取る。演算を複製せず、加法の交換律、左右の分配律、
零元の吸収律を明示する。乗法の交換律は要求しない。

`src/Finite.taut` の `AlgebraFin(n)` は範囲内の添字。`AlgebraFin(0)` に
構成子はなく、添字や行列の形を実行時の unchecked access で補わない。
`AlgebraVector(R, n)` は有限添字から値への関数で、`algebra_sum` は寸法に
関する構造再帰。点ごとの等式の保存、零ベクトルの和、和の加法性、左右の
乗法との分配、二重有限和の交換を帰納法で証明する。

`src/Matrix.taut` は任意の有限行・列数を持つ行列を関数として表す。
零の寸法も扱う。加法、右スカラー倍、行列積、対角単位行列、ベクトルへの作用を
定義し、積の結合律、左右単位律、積の作用と作用の合成の一致を証明する。
行列は密な配列ではなく、与えた関数を評価する表現。計算量や配列への最適化は
これらの証明の主張に含まれない。

ベクトルは **右半加群** の規約を使う。スカラー倍は各成分の右から掛け、
行列の作用は行列成分をベクトル成分の左から掛ける。これにより非可換な半環でも
作用がスカラー倍を保存する。行列自体の右スカラー倍が常に線形写像の右スカラー倍を
与えるとは主張しない。

`src/Linear.taut` の `AlgebraLinear` は、写像と始域・終域の寸法を添字とする
法則の証明。入力の点ごとの等しさ、零、加法、右スカラー倍の保存を要求する。
行列の作用がこの契約を満たすこと、恒等写像と合成が契約を満たすことを証明する。
合成は第一引数の写像を先に適用する。左右単位律と結合律は各入力・各座標の等式。
`AlgebraVectorEq`、`AlgebraMatrixEq`、`AlgebraLinearEq` は点ごとの等しさであり、
関数そのものや法則を含む束の等式を暗黙に要求しない。`funext` は import しない。

この有限線形代数の層は宇宙 0 に限定する。既存の数値宇宙一般化されたモノイド・群・
準同型はそのまま使えるが、ここで高宇宙の有限行列を提供するという意味ではない。
任意の半環と寸法の法則はソース言語の定理。自然数を使った具体例の評価は数学的な
`Nat` の正規化で確認する。Rust backend の有限幅整数、資源使用量、配列処理の
正しさを証明するものではない。

既存の `examples/natural.taut` は加法・乗法モノイドを再利用して自然数半環を作り、
長方形行列の積と作用、零寸法、任意寸法の線形性を検査する。
`cargo test --locked -p tauto --test algebra` は一般的な定理と実例の公理なし検査に加え、
不正な添字、寸法の不一致、誤った演算構造、偽の線形性・行列計算の拒否を検査する。

この半環の法則は carrier の `AlgebraEq` を使う。代表元どうしの別の同値関係で
演算の法則を満たす setoid を、そのままこの行列の係数にはできない。
その接続には正規形の carrier か、同値関係と演算の合同性を明示する半環・行列 API を
使う。「代表元の同値関係と有限行列の接続」の関係版は後者。代表元の同値を通常の等式と同一視しない。

## 代表元の同値関係と有限行列の接続

`src/RelationSemiring.taut` の `AlgebraRelationSemiring` は carrier・同値関係・
零元・単位元・加法・乗法を明示的な引数に取る。`AlgebraSetoid` の証拠と、
両演算の合同性、半環の法則を保持する。`src/RationalSemiring.taut` は既存の
有理数演算と `RationalEq` の定理からこの証拠を構築し、別の有理数表現や演算を作らない。

`src/RelationMatrix.taut` は `AlgebraFin`・`AlgebraVector`・`AlgebraMatrix` と同じ
形の型を使う。有限和、行列の作用、行列積は零元と演算を受け取って計算する。
`AlgebraVectorRelated` と `AlgebraMatrixRelated` は各座標での関係。
有限和、作用、積について、入力代表を同値な代表に替えても結果が同値であることを
任意の寸法で証明する。商型や関数外延性、同値関係から `Eq` への変換は仮定しない。

既存の `AlgebraSemiring` から関係版の法則への adapter があり、関係版の和・作用・積に
既存の演算を与えた結果が、既存の `algebra_sum`・`algebra_matrix_apply`・
`algebra_matrix_product` と各座標で `AlgebraEq` により一致することを証明する。
同値な代表の計算は数学的には同じでも、生の代表として同一とは限らない。

`examples/rational.taut` は同じ非零有理数の分子をずらした代表や約分していない代表を
係数と入力ベクトルに使う。任意の寸法で代表独立性を検査し、正負・零の係数を含む
具体的な行列の作用と積も計算して確かめる。

`cargo test --locked -p tauto --test relation_matrix` は全数学宣言の公理なし検査、
寸法の不一致・不正な同値証明・生の代表の誤った同一視・誤った計算値の拒否を検査する。
積の実装を加法に変える mutation も、既存 API との一致証明によって拒否される。
代表独立性だけでは演算が意図した積であることの保証にならない点を区別する。

この関係版で証明する範囲は代表独立性と既存 API との接続。有理数の係数法則は
法則の証拠として渡すが、関係版の行列積の結合律・単位律や、一般的な関係版の
線形写像の構造はここでは提供しない。既存の `AlgebraEq` 版の証明を、任意の関係へ
無条件に転用したとは主張しない。最適化された数値計算や任意精度 runtime の保証も
このソース言語の証明の範囲外。
