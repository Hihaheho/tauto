# syntax

Tauto's syntax: the parser and scanner tables of `crates/tauto-parol`
(made from `crates/tauto-parol/tauto.par`), written out as data, the `scan` and
`llk` totes that read them, and the tree. The tree and the dump are in the
proof language (`src/syntax.taut`, `docs/design/self-host.md`); `src/syntax.taut`
only passes the texts of `tables.taut` to it, and `src/main.taut` is the
shell.

## tables.taut and tables/

Generated by `bash scripts/generate-syntax-tables.sh`; never edited by hand.
Run the script again after every change to the grammar (`--check` only
compares). A test (`crates/tauto-selfhost/tests/syntax.rs`) fails when a file is
out of date.

There is no literal for a list, so each table is a text of numbers (never
negative) or names separated by single spaces, the whole of
`tables/<name>.txt`; the function `syntax_tables_<name>` of `tables.taut`
returns it with `include_text!` (`docs/design/macro.md`). The names:

| name | holds |
|---|---|
| `terminal_names`, `non_terminal_names` | the parser's names, in order |
| `terminal_kinds`, `non_terminal_kinds` | the names the dump uses |
| `declared` | the non-terminals the grammar declares (not the helper non-terminals made for the EBNF) |
| `parser_meta` | max_k, the start non-terminal, the number of terminals and of non-terminals |
| `skip` | the number of modes; for each, how many terminals the parser skips in it, and which |
| `lookahead_meta` | the number of automata; for each non-terminal `prod0 + 1` (0 for none), `k`, the number of states |
| `lookahead_cells` | run-length encoded (pairs: how many, which value) over every automaton's states in order and each state's terminals: `next state * 1024 + production + 1`, 0 for no transition |
| `productions` | the number of productions; for each the left side, the number of symbols and the symbols as pairs (0 non-terminal, 1 terminal; the number), in the order the parser pushes them |
| `scan_meta` | the number of classes, of modes, of automata; for each mode its number of transitions and each as (kind: 0 set, 1 push, 2 pop; terminal; mode) |
| `scan_classes` | the number of runs; each as first and last code point and class |
| `scan_states` | for each automaton its number of states; for each state its number of accepts and each as (terminal, lookahead kind: 0 none, 1 positive, 2 negative; automaton) |
| `scan_rows` | for each state, run-length encoded: the next state + 1 (0 for none) for each class; automaton 0 to the number of modes - 1 are the modes' |

## The tree

`syntax.taut` also builds the tree `crates/tauto-parol/src/cst.rs` builds from the events of
`llk`: a node is a non-terminal or a terminal with its start and end and its
children. A non-terminal's span is the merge of its children's, leaving out
trivia (white space and comments); a span that is empty at 0 counts as none.
The tree is a value, not a vector of nodes: Nib has no store into a vector.

## The dump

For each node, parent first and children in order, whitespace and comments
included and nothing flattened, a line

```text
<depth> <kind> <start> <end>
```

The root has depth 0; its kind is `Root`. `tauto_parol`'s `Cst::dump` writes
the same.

`main.taut` prints `== <path>` and the dump of each file named on the command
line, or `error`. With `--tokens` first it prints the scanner's tokens only,
`<kind> <start> <end>`.
